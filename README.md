- `index.html`: 프로그램 소개 및 신청 안내

- 메인 제목 `글로벌플러스 / 중국`은 본문과 같은 Noto Sans KR을 사용하되, 중간보다 약간 굵은 600 웨이트로 조정했습니다.
- 포스터의 기울어진 인상은 살리면서 Gmarket Sans Bold의 과한 두께를 줄였습니다.

## GitHub Pages 배포 및 업데이트
1. ZIP을 압축 해제합니다.
2. 압축 해제한 폴더 안의 `index.html`, `styles.css`, `config.js`, `README.md`, `assets` 폴더를 저장소 최상위(root)에 업로드합니다.
3. 이미 같은 경로에 있는 파일은 최신 파일로 교체합니다. 저장소 전체를 삭제할 필요는 없습니다.
4. `Commit changes`를 누릅니다.
5. GitHub Pages는 새 커밋을 기준으로 자동 배포를 시작합니다. ZIP을 내려받기만 해서는 공개 웹사이트가 바뀌지 않습니다.
