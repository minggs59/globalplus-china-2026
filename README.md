# 2026학년도 동계 글로벌플러스(중국) 안내 웹사이트

이 ZIP은 GitHub Pages 사이트 전체를 복구·업데이트하기 위한 완성본입니다.

## 업로드 구조
- `index.html`: 첫 화면, 필독 공지, 확정 일정, 다운로드 링크
- `styles.css`: 기존 디자인 및 최종 제목 정렬/CHINA 글자 수정
- `config.js`: 네이버폼 주소
- `assets/`: 학교 로고, 파비콘, 호텔 사진, 지원서, 최신 세부계획안 PDF

## GitHub에 올리는 방법
1. ZIP을 압축 해제합니다.
2. 압축 해제 폴더 안의 파일과 `assets` 폴더를 GitHub 저장소 최상위에 업로드합니다.
3. 기존 같은 경로의 파일은 새 파일로 덮어씁니다.
4. `assets` 폴더는 통째로 유지하고, `assets/hotels` 하위 폴더도 삭제하지 않습니다.
5. Commit changes를 누릅니다.

업로드 후 `index.html`, `styles.css`, `config.js`, `assets/`가 저장소 최상위에 함께 있어야 합니다.
