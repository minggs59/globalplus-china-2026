- `index.html`: 안내 웹사이트 본문

### 연수 장소와 시간 확인
- 사업계획서 1쪽의 공식 연수 장소 표기는 `중국 린이대학/린이시`입니다.
- 다만 사업계획서 3쪽 행사일정표에는 1일차 칭다오 도착, 4일차 린이에서 칭다오 이동 후 칭다오 맥주박물관 및 5·4광장 방문, 5일차 칭다오 출발이 적혀 있습니다. 따라서 사이트는 주요 연수 거점(린이)과 일정 중 방문 지역(칭다오)을 구분해 표기합니다.
- 연수 시간 40시간은 사업계획서 1쪽 `연수 시간: 40시간(8시간/일 × 5일)` 표기를 따릅니다.

## 로고 처리
- 상단 및 하단에 동일한 파란색 공식 시그니처 PNG를 사용합니다.
- 로고 PNG는 알파 투명 배경이며, 보이는 로고 픽셀에서 검정색 픽셀을 사용하지 않았습니다.
- 검정색 로고 파일은 웹사이트에서 사용하지 않습니다. 상단 폭은 285px, 하단 폭은 265px로 이전보다 확대했습니다.

## GitHub Pages 배포
1. ZIP을 압축 해제합니다.
2. 압축 해제한 폴더의 `index.html`, `styles.css`, `config.js`, `README.md`, `assets` 폴더를 저장소 최상위(root)에 업로드합니다.
3. 같은 경로에 같은 이름의 파일이 있으면 새 파일로 교체하고 `Commit changes`를 누릅니다.
4. GitHub Pages는 저장소에 커밋이 올라오면 자동으로 다시 배포합니다. 단, 이 ZIP을 내려받는 것만으로 GitHub 저장소가 바뀌지는 않으며, 새 버전을 업로드하고 커밋해야 사이트에 반영됩니다.
5. 공개 주소: https://minggs59.github.io/globalplus-china-2026/
