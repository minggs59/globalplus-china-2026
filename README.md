## GitHub에 최신본 반영하기
1. ZIP을 압축 해제합니다.
2. 압축을 푼 폴더 안에 있는 `index.html`, `styles.css`, `config.js`, `README.md`, `assets` 폴더를 확인합니다.
3. 이 파일과 폴더를 GitHub 저장소 `minggs59/globalplus-china-2026`의 **최상위(root)** 에 업로드합니다. `index.html`이 저장소 첫 화면에 바로 보여야 합니다.
4. 기존 파일과 경로가 겹치는 경우에는 새 파일을 기존 파일의 **교체본**으로 반영합니다. `assets` 폴더도 폴더째 최상위에 올려 파일 경로가 `assets/...`로 유지되게 합니다.
5. `Commit changes`를 눌러 저장합니다.

## GitHub Pages 공개 설정
1. 저장소 `Settings` → `Pages`로 이동합니다.
2. `Build and deployment`의 Source를 `Deploy from a branch`로 선택합니다.
3. Branch는 `main`, Folder는 `/(root)`로 선택하고 `Save`를 누릅니다.
4. 배포가 완료되면 다음 주소에서 확인합니다: https://minggs59.github.io/globalplus-china-2026/
