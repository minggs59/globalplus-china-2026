## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. 압축을 푼 폴더 안의 파일과 `assets` 폴더를 저장소 최상위(root)에 업로드합니다.
3. 기존 파일과 같은 경로의 파일은 새 파일로 교체하고 `Commit changes`를 누릅니다.
4. 저장소의 `Settings` → `Pages`에서 `main` 브랜치와 `/(root)`가 설정되어 있으면 커밋 후 자동 배포됩니다.
5. 공개 주소: https://minggs59.github.io/globalplus-china-2026/
